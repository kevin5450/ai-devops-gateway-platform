# Architecture

이 문서는 `ai-devops-gateway-platform`의 예정 아키텍처를 정리하기 위한 문서입니다.

현재 단계에서는 실제 구현 없이 전체 구성 방향만 정의합니다.

## 예정 구성

- React Web Client
- Spring Boot Gateway Service
- Node.js 또는 Python 기반 AI Service
- Spring Boot Log Service
- Redis
- Kafka
- MongoDB
- Docker Compose
- Kubernetes manifests
- GitHub Actions
- k6
